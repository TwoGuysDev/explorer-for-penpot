# Changelog

All notable changes to Explorer for Penpot are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.2.2] - 2026-11-22

### Fixed

- Preview: inside flex and grid layouts, absolute-positioned children (such as dialogs over a board) are painted above the other children, and children follow their layout z-index, as in Penpot.

## [0.2.1] - 2026-11-20

### Fixed

- Penpot Cloud: use the current API path (`/api/main/methods`); the legacy one is behind a bot challenge and answered HTTP 403.
- Clearer error messages when connecting, including when a server answers with a browser challenge.

## [0.2.0]

First public pre-release.

### Added

- Sidebar explorer: teams → projects → files → pages → boards.
- Board and page preview drawn as SVG: layouts, text, images, gradients, strokes, shadows and blur.
- Comparison with the thumbnail generated by the Penpot editor, when available.
- “Open in Penpot” for files, pages and boards.
- Connect flow for Penpot Cloud and self-hosted instances; the token is verified and stored in VS Code's secret storage.
- English and Brazilian Portuguese.
- Setting to load (or not) web fonts in the preview.
