# Changelog

All notable changes to Explorer for Penpot are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- MCP `edit`: icons. `create` with type `svg` turns SVG markup (paths, basic shapes, groups, transforms) into Penpot paths, and type `path` takes SVG path data with a `viewBox`; both are scaled to the requested size. Paths can be resized and laid out like other shapes.
- MCP `edit`: layers of a shape created or duplicated with `ref` can be used in the same call as `$ref/Child/Grandchild`, and `duplicate` lists the new id of every copied layer.

### Fixed

- MCP `edit`: without `index`, a new or moved shape goes last in a flex layout's flow (it used to go first, so screens came out in reverse order), and a duplicate goes right after its original.
- MCP `screenshot`: texts not yet laid out by Penpot wrap to their width and follow their horizontal and vertical alignment; Inter and Source Sans are built in, so texts keep their real widths.
- The MCP server starts when VS Code opens (when it is enabled), not only after the Penpot view was opened.

## [0.5.0] - 2026-11-25

### Added

- **MCP server** (off by default; **Penpot: Start MCP Server**): AI assistants such as Claude Code can read and edit the `.penpot` files of the workspace, with no browser and no Penpot server. Tools: `list_designs`, `get_structure`, `get_layers`, `get_shapes`, `edit` (create, update, move, duplicate, delete in one batch) and `screenshot` (PNG). Flex boards are laid out again after each edit, as Penpot does. Listens on `127.0.0.1` only.

## [0.4.0] - 2026-11-23

### Added

- **Workspace Files** view in the Penpot sidebar: every `.penpot` in the workspace as a tree (file → pages → boards), offline. A click on a board opens the preview at that board; files and pages have a preview button, and `.penpot` files get “Open Penpot Preview” in the Explorer context menu.

## [0.3.0] - 2026-11-22

### Added

- Open `.penpot` files from the workspace: a click shows their pages and boards drawn offline, with the images and thumbnails stored in the export, and the view follows changes to the file.

## [0.2.2] - 2026-11-22

### Fixed

- Preview: inside flex and grid layouts, absolute-positioned children (such as dialogs over a board) are painted above the other children, and children follow their layout z-index, as in Penpot.

## [0.2.1] - 2026-11-20

### Fixed

- Penpot Cloud: use the current API path (`/api/main/methods`); the legacy one is behind a bot challenge and answered HTTP 403.
- Clearer error messages when connecting, including when a server answers with a browser challenge.

## [0.2.0]

First public pre-release.

### Added

- Sidebar explorer: teams → projects → files → pages → boards.
- Board and page preview drawn as SVG: layouts, text, images, gradients, strokes, shadows and blur.
- Comparison with the thumbnail generated by the Penpot editor, when available.
- “Open in Penpot” for files, pages and boards.
- Connect flow for Penpot Cloud and self-hosted instances; the token is verified and stored in VS Code's secret storage.
- English and Brazilian Portuguese.
- Setting to load (or not) web fonts in the preview.
